Nigerian Address Normalization & Geocoding API (1.0.0)

Download OpenAPI specification:

Turn messy Nigerian address text into structured parts and an honest coordinate.

Nigerian addresses are often written relative to landmarks, and no authoritative address register covers the country. This API therefore never returns a bare coordinate: every answer carries a precision class, a radius and a confidence, and when the evidence only supports an area the answer says so (or returns none with no coordinate).

Precision classes

Class Meaning Claimed radius
building On or inside a building 50 m
street On the named road 300 m
locality Centre of a named neighbourhood or landmark area 2 km
lga Local government area (representative point) the area's extent
state State (representative point) the state's extent
none Nothing resolved; no coordinate not applicable

Confidence is calibrated: among answers with confidence 0.8 or higher, at least 90% are expected to fall inside the claimed radius.

Authentication and rate limits

Send your API key in the X-API-Key header. Each operation lists the scope it needs in x-required-scopes. Limits apply per tenant (default 60 requests a minute) and are reported on every response in the RateLimit-* headers; a 429 adds Retry-After. A batch call costs one request plus one more for every 10 addresses.

Errors

Every error is an RFC 9457 problem document (application/problem+json) with a stable code. An address that cannot be resolved is not an error: it returns 200 with precision none.

Privacy

Raw address text is not logged. Tenants may opt in to keeping it for up to 30 days.

Geocoding

Normalize and geocode address text.

Split an address into its parts

Expands Nigerian abbreviations (opp., b/stop, rd.), separates landmarks and their relation (opposite, beside, behind) and extracts house number, street, area, LGA, state and postcode. No coordinate is computed.

Geocode one address

Returns the best coordinate the evidence supports, with its precision class, radius and confidence, plus ranked alternative candidates and warnings. If nothing resolves, the response is still 200 with result set to null; a pin is never faked.

Geocode up to 100 addresses in one call

Each address is resolved independently and the results come back in order. The whole call is rejected with 422 if any item breaks the schema (the errors name the item, for example items[3].address); otherwise it returns 200 and each result carries its own status. A batch costs one request plus one more for every 10 addresses.

Corrections

Send back a confirmed location to improve evaluation.

Submit a confirmed location for an earlier request

Tells us where an address really is. The request_id must belong to a recent geocode call made by your tenant; otherwise the response is 404. Corrections are stored for offline evaluation and do not change answers automatically. One correction per request.
